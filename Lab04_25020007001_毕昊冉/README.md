## 操作流程

1. 输入初始值，点击“载入初始值”。只有有限实数可以成功载入
2. 选择运算。加、减、乘、除需要第二操作数；平方、平方根、倒数会隐藏第二输入
3. 点击“执行”。成功后显示完整运算说明，结果成为新的当前值，可以继续运算
4. 再次成功载入会开始新链并清空原链记录；非法载入保留原当前值、载入状态和记录
5. 点击“重置”清空输入和消息，回到未载入状态；执行会提示先载入。下拉框保留之前的运算选择

初始输入框可以编辑，当前值 Label 只读，后续计算使用字段 `initialVar`，不重新解析显示文字

## 状态与错误处理

- `hasLoading` 区分未载入和可计算；只在载入校验通过后置为 true
- 二元操作数通过 `TryParse` 和 `double.IsFinite` 校验。一元运算不使用第二操作数，即使残留 abc 也能执行
- 除零、负数开方、零的倒数会被拒绝，保留当前值
- `result` 在提交之前检查有限性，溢出结果不更新当前值，也不加入成功记录
- 消息列表只记录当前链的成功运算；失败操作只弹窗，重新成功载入或重置会清空记录

## 计算链与测试

指定链：`3 > +5 得8 > 平方得64 > ÷2 得32 > 倒数得0.03125`

自选链：`2 > +3 得5 > ×4 得20 > -2 得18 > ÷3 得6 > 平方得36`，包含五种运算。两条链各步均与手算一致

已回归首次非法载入、已有链非法重载、独立减法与乘法、0 的倒数、二元非法输入、NaN、超范围输入和乘法/平方/倒数溢出。详见计算链测试记录
